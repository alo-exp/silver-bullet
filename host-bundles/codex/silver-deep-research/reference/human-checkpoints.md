# Human Checkpoints (narrow)

Pause **only** when:

1. **Ambiguous scope** — question admits mutually incompatible framings
2. **Provider signup** — user requested deep/ultradeep depth but no provider can satisfy breadth
3. **Mutually exclusive conclusions** — evidence supports irreconcilable recommendations
4. **User-owned decision** — product/policy choice only the user can make

## Do NOT pause for

- Ordinary quick/standard research with clear scope
- Missing optional providers when fallback meets threshold
- Routine citation repairs inside repair loop budget

Record checkpoint in `handoff.md` with `checkpoint_type` and resume instructions.
