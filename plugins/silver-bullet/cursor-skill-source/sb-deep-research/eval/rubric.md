# SB Deep Research Capability Rubric

11 dimensions — **capability only** (no stars, installs, recency popularity).

| Dimension | Max | Criteria |
|-----------|-----|----------|
| Phases/Modes | 5 | phases.yaml SSoT, mode budgets, file gates |
| Citation/Evidence | 5 | JSONL ledgers, Admiralty grading, verify_claim_support |
| Search Providers | 5 | search-cli + fallback + SB portals (landscape) |
| Multilingual | 5 | en/zh report profiles, language-aware validation |
| Report Formats | 5 | Block library, chapter assembly, metadata |
| Validation/Eval | 5 | validate_report, eval harness, structure checks |
| Portability | 5 | Host-agnostic artifacts under .planning/research/ |
| Human-in-Loop | 5 | Narrow checkpoints only |
| Composability | 5 | AF-DECIDE, V-loops, handoff |
| Source Catalogs | 5 | intent_classes, channels, domain matrices |
| Adversarial | 5 | DR-CRITIQUE cycles, structured deltas |

**Total max:** 55

## Behavioral metrics (lagging)

Report separately from rubric score:

- source count / diversity
- unsupported claim count
- citation verification status
- validation failure count
- fallback/provider status
- human-checkpoint count
