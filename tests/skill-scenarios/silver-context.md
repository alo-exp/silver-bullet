# Silver Context Skill Scenario

## Skill: silver-context
## Context: Pre-plan context capture

### Scenario: Gather Feature Context

**Trigger:** "Gather context for this change"

**Workflow:**
1. Read relevant project docs, Graphify results, and existing artifacts.
2. Capture constraints, assumptions, risks, and open questions.
3. Identify source areas likely affected.
4. Produce context for planning.
