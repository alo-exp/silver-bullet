# Silver Secure Skill Scenario

## Skill: silver-secure
## Context: Security hard gate

### Scenario: Security Review Before Ship

**Trigger:** "Run security gate"

**Workflow:**
1. Inspect changed code, config, and scripts.
2. Check secrets, command injection, path traversal, and permissions.
3. Record findings and required fixes.
4. Approve only after security blockers are closed.
