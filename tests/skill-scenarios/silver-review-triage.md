# Silver Review Triage Skill Scenario

## Skill: silver-review-triage
## Context: Review finding handling

### Scenario: Triage Review Findings

**Trigger:** "Address review feedback"

**Workflow:**
1. Classify findings by severity and actionability.
2. Decide fix, defer, or reject with rationale.
3. Verify fixes against the original finding.
4. Record a clean review pass.
