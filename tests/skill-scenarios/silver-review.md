# Silver Review Skill Scenario

## Skill: silver-review
## Context: SB-owned code review

### Scenario: Review Implemented Changes

**Trigger:** "Review the implementation"

**Workflow:**
1. Read diff, plan, and relevant artifacts.
2. Prioritize correctness, regressions, and missing tests.
3. Write review findings to the planning artifact.
4. Require fixes for blocking findings.
