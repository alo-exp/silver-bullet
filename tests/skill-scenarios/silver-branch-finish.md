# Silver Branch Finish Skill Scenario

## Skill: silver-branch-finish
## Context: Branch readiness

### Scenario: Prepare Feature Branch For PR

**Trigger:** "Finish this branch"

**Workflow:**
1. Inspect git status, changed files, tests, and docs.
2. Separate unrelated user changes.
3. Choose PR, merge, continue, or stop.
4. Record explicit next branch action.
