# Silver Completion Audit Skill Scenario

## Skill: silver-completion-audit
## Context: Completion evidence

### Scenario: Audit Before Declaring Done

**Trigger:** "Can I call this complete?"

**Workflow:**
1. Compare required gates with recorded evidence.
2. Check review, test, docs, and delivery artifacts.
3. Identify missing proof or stale verification.
4. Approve completion only after evidence is current.
