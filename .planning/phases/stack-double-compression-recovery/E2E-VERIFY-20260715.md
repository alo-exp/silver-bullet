## Root Cause Recap (fixed in v0.51.4+)

1. **False positive:** `install-leanctx-sb.sh` in bash command path triggered leanctx shell marker → spurious mutex. **Fixed:** path exempted in `sb_stack_bash_leanctx_shell_marker`.
2. **No recovery:** Dirty mutex blocked all tools with no compliant escape. **Fixed:** `sb_stack_record_routed_owner_success` clears mutex on compliant routed MCP/Bash.
3. **Manual recovery:** `/silver:clear-stack-state`, doctor D20 `--fix`, lib `sb_stack_clear_mutex_violations`.
