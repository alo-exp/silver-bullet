# DR-SCOPE — Deep Research Skills Landscape

## Bounded question

Which **10 agent deep-research skills** (GitHub repos and skills portals, July 2026) deliver the strongest **capability/feature mix** for rigorous, citation-backed research — ranked by features, not popularity?

## Success criteria

- ≥20 candidate skills discovered independently (not limited to four prior picks)
- Feature matrix across ≥10 dimensions with evidence spans
- Top-10 ranking with 1-line rationale tied to feature scores
- Artifacts under `.planning/research/2026-07-07-deep-research-skills-landscape/`

## In scope

- Claude Code / Cursor / Codex / OpenClaw / pi / skills.sh skills whose primary purpose is **deep research** (multi-phase, multi-source, cited reports)
- Retrieval infrastructure skills tightly coupled to research workflows (e.g., OpenClaw search-layer)
- SB native `silver-deep-research` as benchmark

## Out of scope

- Closed commercial DR products (ChatGPT Deep Research, Gemini DR) except as comparison context
- Generic `web_search` wrappers with no phased methodology
- Academic course repos (e.g., ARENA alignment curriculum)
- Social-only briefings (e.g., last30days) unless they implement full DR phases

## Assumptions

- Feature claims validated from `SKILL.md`, `README.md`, or repo API when raw URLs 404 on wrong branch
- Stars noted but **not** used as primary rank signal
- Date anchor: **2026-07-07**

## Mode rationale

**deep** — comparative landscape with conflicting marketing claims and architecture diversity; requires critique + refine phases.
