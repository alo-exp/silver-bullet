# Learnings — 2026-08

## practice:documentation

2026-08-08 — A documentation gate should inventory current guidance, not every preserved file. Treating audits, research, session notes, and completed plans as live guidance creates noisy checklists and hides genuine drift.

2026-08-08 — When an old document is valuable evidence but contradicts current architecture, preserve its body and add a visible historical-status banner with authoritative replacement links.

## practice:release

2026-08-08 — Release-parity tests should derive one canonical version and assert every user-visible and machine-consumed release surface, including support-policy series and configuration schema versions.

2026-08-08 — Pre-commit archive-install tests must package the working tree under review. Packaging committed `HEAD` silently tests old code and makes a valid local fix appear ineffective.
