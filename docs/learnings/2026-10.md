# Learnings — 2026-10

## practice:documentation

2026-10-17 — Numbers in prose (component counts, registrations, versions) go stale fastest. State them next to their source of truth and add a test that recomputes them, or leave them out.

2026-10-17 — When several pages describe the same list (enforcement layers, release stages), pick one owner page, make the others summarize and link to it, and keep the summaries structurally identical so drift is visible in review.

2026-10-17 — Verify every command a document tells readers to run. Some tools treat unknown flags as positional arguments or ignore them and run for real.

## practice:testing

2026-10-17 — A CI assertion that greps for a literal which no longer exists passes vacuously. Assertions should fail when their input is missing, not only when the input is wrong.
