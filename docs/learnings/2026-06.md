2026-06-14 — Doc-scheme enforcement is mtime-based against `session-start-time`, not git commit time. Remediation requires editing the mandated files during the active session after updating the checklist.

2026-06-14 — Release gate remediation must update `docs/RELEASE.md` when adding post-create validation (`validate-github-release-notes.sh`) and `docs/ENFORCEMENT.md` when cross-runtime receipt lookup behavior changes.

2026-06-08 — When a plugin supports multiple host runtimes, public docs should describe the shared contract first and host-specific invocation mechanics second. Otherwise one runtime's terms become stale product claims for another runtime.

## practice:testing

2026-06-14 — v0.39.2 fixed `tests/run-all-tests.sh` stdin hang (commit 481849d): each test invocation uses `bash "$test_file" </dev/null` inside command substitution. Without the redirect, a single hook test reading stdin blocks the full 3000+ test suite when run from an agent shell with open stdin.

2026-06-14 — `tests/run-all-tests.sh` should invoke each `test-*.sh` with `</dev/null` because `output=$(bash "$test_file" 2>&1)` inherits open stdin from agent shells and hooks using `input=$(cat)` will block the entire suite.

2026-06-14 — Hook unit tests that invoke hooks without stdin must pipe `{}` or valid JSON; otherwise `input=$(cat)` blocks forever when the agent shell keeps stdin open.

2026-06-14 — Full `verify-tests` output piped to `tail` appears hung because `tail` buffers until the producer exits; use `tee` to a log file or run without tail when monitoring long suites.

2026-06-11 — For release gates that run in isolated homes, a passing live suite is insufficient unless the test also proves the host-side release marker exists where the completion hook reads it.

2026-06-11 — Live hook tests for runtimes that may ignore hook exit status need a two-layer assertion: the native before-hook must return a blocking status, and fallback filesystem locks must independently stop direct mutation paths such as Python writes, shell redirects, chmod retries, and direct `git commit` with an absolute Git binary.

2026-06-10 — Retrieval tools that produce ranked graph results should be treated as advisory until the returned nodes are inspected. Broad queries can match workflow or documentation nodes before implementation nodes.

2026-06-10 — Code-only graph refreshes are the safest default for docs-heavy repos without LLM credentials; semantic extraction should be treated as an enhanced path with explicit credential prerequisites.

2026-06-08 — Structural manifest tests are useful for cross-runtime hook reliability: assert equivalent trigger surfaces for runtime-specific tool names instead of relying only on individual hook unit tests.
