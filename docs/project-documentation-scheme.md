# Project Documentation Scheme

> Compatibility wrapper. The canonical documentation contract for SB projects is [doc-scheme.md](doc-scheme.md) and [doc-scheme.json](doc-scheme.json).

This page is retained for older links and historical references. It no longer carries separate policy. Downstream projects receive the same contract from `templates/doc-scheme.md.base` and `templates/doc-scheme.json.base` during `/sb:init`.

Current pointers:
- [doc-scheme.md](doc-scheme.md) for the human policy companion
- [doc-scheme.json](doc-scheme.json) for the machine-enforced contract
- [task-doc-checklist.json](task-doc-checklist.json) for the current per-task checklist contract

If you are updating scaffolding or enforcement, use the canonical doc-scheme files instead of extending this compatibility page.
