# Lessons Learned — 2026-06

## practice:documentation

2026-06-08 — When a plugin supports multiple host runtimes, public docs should describe the shared contract first and host-specific invocation mechanics second. Otherwise one runtime's terms become stale product claims for another runtime.

## practice:testing

2026-06-08 — Structural manifest tests are useful for cross-runtime hook reliability: assert equivalent trigger surfaces for runtime-specific tool names instead of relying only on individual hook unit tests.
