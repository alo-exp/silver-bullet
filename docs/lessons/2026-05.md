# Lessons Learned — 2026-05

## practice:testing

2026-05-07 — When the same behavior must be proven in multiple runtimes, keep one scenario suite and swap only the runtime adapter. Duplicating scenario bodies creates drift and makes failures harder to compare. Serialize runs if both runtimes touch shared state.

## practice:packaging

2026-05-07 — When a target runtime lacks a native plugin package, ship a thin wrapper that fetches the authoritative upstream content at install time. The wrapper should be registry-only, not a second copy of the real plugin.

## devops:automation

2026-05-07 — Schedule-based automations are predictable but cost proportional to invocation count. If an event-driven trigger exists, prefer it for issue triage or alerting; otherwise bridge with the source system (for example via webhook or CI) instead of polling more often than needed.

## practice:release

2026-05-07 — Multi-runtime releases should treat each supported runtime as a first-class release target. The release gate should verify every runtime path you ship, not just the primary one.

## practice:documentation

2026-05-08 — A checklist is only enforceable if its keyset is computed from reality, not hand-picked. For per-task doc governance, derive required checklist keys from the current docs inventory and fail when any governed doc is missing from the checklist.

2026-05-08 — For high-confidence documentation governance, keep a human-readable policy plus a machine-enforced JSON contract. Put enforcement knobs (granularity levels, mandatory docs, required sections) in the contract and keep hooks contract-only.

2026-05-08 — Brownfield documentation migrations should be reversible and auditable by default. If users switch to canonical docs, move old artifacts into an archive namespace and persist a move manifest with task linkage.

2026-05-10 — If two docs describe the same scheme, keep only one as the canonical policy and convert the others into short compatibility wrappers. Duplication makes the active contract harder to find and easier to drift.
