## Known Gotchas

2026-06-14 — `scripts/sb-diagnostics.sh` is the canonical operator entry for AS1 parity diagnostics (receipt dirs, hook manifest, state files, verify-tests marker). Prefer it over ad-hoc `ls`/`cat` when triaging release-gate or cross-runtime receipt mismatches.

2026-06-14 — `tests/run-all-tests.sh` must redirect stdin (`</dev/null`) when capturing per-test output; command substitution inherits the parent shell's open stdin and hook tests that read stdin can hang the full suite indefinitely.

2026-06-14 — Codex `silver-bullet invoke-skill` writes adapter receipts under `~/.codex/.silver-bullet/skill-invocations`, but repo-source hooks can auto-detect the Claude runtime and search `~/.claude/…` instead. `record-skill` must search all candidate receipt dirs via `sb_runtime_skill_receipt_dirs()`, and `CLAUDE_PLUGIN_ROOT` paths under `/.codex/` should force codex runtime detection.

2026-06-14 — `docs/doc-scheme.json` gate compares mandated doc file mtimes against `${SB_RUNTIME_STATE_DIR}/session-start-time`. Marking a checklist entry `updated` without editing the underlying file in the current session will still block completion.

2026-06-14 — Doc-scheme checklist `task_id` must align with the active session task slug; renaming a task without rewriting the checklist blocks stop/completion gates even when all `docs` keys are present.

2026-06-11 — Release live gates that run agents inside isolated Codex or Kay homes must mirror their final `release-live-matrix`, `e2e-live-matrix`, and `inline-e2e-matrix` markers back to the host `SB_RUNTIME_STATE_DIR`. Markers written only inside the isolated home are lost or ignored by `completion-audit.sh`, and the runner must let `runtime-paths.sh` infer the host runtime before computing those host marker paths.

2026-06-11 — Release live gates must preserve the host `verify-tests-state` marker while isolated agents run. Isolated Kay/Codex turns may invoke their own `verify-tests` flow and otherwise overwrite the host full-suite marker with an unrelated fixture or runtime build marker, weakening the release freshness gate.

2026-06-11 — The release live matrix wrapper must require a host `verify-tests-state` marker before running and restore it afterward. Runner-level preservation is not enough because a missing marker at wrapper entry would otherwise let the live matrix pass while the final completion audit has no full-suite freshness evidence.

2026-06-11 — Kay hook call IDs may differ between before and after events by suffix (`_hook_tool_before_1`, `_hook_tool_after_1`, and file-write variants). Bridge state keys must normalize those suffixes or fallback filesystem locks can survive after-hook cleanup and poison later release-gate checks.

2026-06-10 — Graphify `0.8.36` requires Python 3.10+; the system Python 3.9 cannot install `graphifyy`. Use a Python 3.12 runtime or `uv tool install graphifyy`.

2026-06-10 — For SB-style repos with substantial docs, `graphify update . --no-cluster` is the no-key local code-index path. Full `graphify extract .` requires an LLM key when docs, Markdown, HTML, PDFs, or images are present.

2026-06-10 — Optional Graphify surfaces need optional dependencies: `watchdog` for `graphify watch`, `psycopg` plus a reachable database for `graphify extract --postgres`, and `graphifyy[mcp]` for HTTP MCP serving.

2026-06-09 — `/silver:research` is intentionally stricter than feature/UI optional review paths: it performs direct evidence-based research by default and only uses MultAI when the current user request explicitly asks for multi-AI, second-opinion, cross-model, or similar perspectives.

2026-06-08 — Quoted `~/.codex` or `~/.claude` paths in generated shell snippets do not expand. Generated runtime placeholders should use `$HOME/.codex` or `$HOME/.claude` when the value may land inside quotes.
