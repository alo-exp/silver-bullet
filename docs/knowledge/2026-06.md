# Project Knowledge — 2026-06

## Architecture Patterns

2026-06-08 — Codex packaging keeps SB's internal generated skills under `plugins/silver-bullet/skill-source/` and mirrors them into native `~/.codex/skills` during install. This prevents plugin-prefixed duplicate picker entries while preserving package-local skill sources for adapters and installers.

## Known Gotchas

2026-06-08 — Quoted `~/.codex` or `~/.claude` paths in generated shell snippets do not expand. Generated runtime placeholders should use `$HOME/.codex` or `$HOME/.claude` when the value may land inside quotes.

## Key Decisions

2026-06-08 — Codex hook trigger parity must be asserted structurally: Claude `Bash` hook groups need Codex `exec_command` equivalents, and edit/write guard groups need `apply_patch` coverage.

## Recurring Patterns
