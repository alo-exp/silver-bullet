# Scope

**Question:** Which open-source GUI applications best drive the [Pi coding agent](https://pi.dev) (`@earendil-works/pi-coding-agent`) as a native subagent shell or dedicated Pi GUI?

**In scope:** Desktop apps, browser UIs, and IDE extensions that wrap the official Pi coding-agent SDK/CLI rather than reimplementing a separate agent runtime.

**Out of scope:** Terminal-only TUI (`pi` CLI), unrelated Inflection "Pi" chatbot, generic AI IDEs without Pi integration, and browser-automation extensions that give Pi page control but are not GUIs for the agent itself.

**Date:** 2026-07-10 (UTC). **Mode:** deep. **Type:** solution-landscape.
