# Solution Capability Report: GitHub spec-kit

Slug: `spec-kit`

## Executive summary

GitHub spec-kit makes specifications executable via constitution.md principles and spec-driven development workflows.

## Evidence-backed notes

- GitHub Spec Kit is MIT-licensed and describes itself as an extensible, intent-driven harness that pushes any coding agent beyond code, across the SDLC — direct process layer above host runtime positioning from a first-party vendor.
- Spec Kit introduces constitution.md as a set of non-negotiable project principles enforced across phases — the closest OSS analogue to a policy layer, though enforcement is agent-interpreted rather than hook-blocked.
- Spec Kit supports 29+ named agent integrations plus a generic adapter (Claude Code, Copilot, Gemini CLI, Cursor, Codex CLI, Windsurf, Goose, Roo Code and others) — the broadest host portability in the comparison set.
- Spec Kit's persistent spec artifacts serve as the cross-session state mechanism (specification as source of truth) rather than a runtime state machine.
- The secondary market splits cleanly on enforcement mechanism: Silver Bullet and microsoft/conductor use machine-checkable blocking gates, while BMAD, Spec Kit, Superpowers and Ruflo rely on prompt-, artifact-, or persona-level discipline that an agent can in principle skip.
- GitHub Spec Kit provides a spec-first methodology pack with constitution/plan/tasks artifacts; satisfies multi-phase lifecycle coverage + plugin/skill/hook packaging + cross-session state (specs persisted).
- APO secondary market (SDLC plugins) is formidable substitutes territory: BMAD, GSD, Superpowers, Spec Kit, SuperClaude, Ruflo, OMP, Zuvo collectively cover plan→spec→build→test→review→ship with varying gate depth. Solution cards must include them, not demote to Adjacent.
- GitHub Spec Kit enforces spec-driven development methodology via OSS tooling — structured planning, spec-first workflow, host-integrated with GitHub ecosystem.
- APO targeting does NOT exclude secondary-market OSS/plugin substitutes: BMAD, GSD, Superpowers, Spec Kit, OMP, Zuvo, SuperClaude, Ruflo all appear in solution cards and charts as formidable SB substitutes even when adjacent to APO.
- SDLC Plugins & Methodology Packs (BMAD, GSD, Superpowers, GitHub Spec Kit, SuperClaude, Ruflo, Oh My Pi) represent formidable substitutes in secondary market. These OSS packs typically satisfy 3-5 of 7 APO inclusion criteria — strongest on multi-phase lifecycle coverage and packaging, weakest on cross-session state and deterministic quality gates.
