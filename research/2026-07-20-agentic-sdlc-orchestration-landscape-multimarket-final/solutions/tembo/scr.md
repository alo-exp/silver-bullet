# Solution Capability Report: Tembo

Slug: `tembo`

## Executive summary

Tembo runs cloud agents across repos, tickets, and tools with reviewable sessions and automations for startup engineering teams.

## Evidence-backed notes

- Tembo delegates work to Claude Code, Cursor and Codex across repos, triggered from Slack, Linear, GitHub and Sentry — a managed orchestration layer above host runtimes, qualifying it as a tertiary-market APO substitute despite no APO self-label.
- Tembo enforces a human approval gate so nothing merges unreviewed, runs each agent in an isolated cloud VM preloaded with repo and dependencies, supports self-hosted VPC deployment, and claims no single-agent/model lock-in.
