## Key Findings

1. **The comparison document frequently uses Claude Code terminology** (e.g., `session_start`, `session_stop`, `session_before_compact`, `tool_approval_requested`) rather than omp's actual API names (`agent_start`, `agent_end`, `beforeToolCall`, `afterToolCall`, `onTurnEnd`).

2. **omp's actual hook API** is: `beforeToolCall` (can block + has `transformToolCallArguments`), `afterToolCall` (can modify result), `transformAssistantMessage`, `onTurnEnd`, `onRunEnd`, and `subscribe()` for event streaming.

3. **Claim #4 is factually wrong**: omp has `transformToolCallArguments` which rewrites tool call input before execution.

4. **Claim #9 is factually wrong**: There is no `session_stop` hook; the event is `agent_end`.

5. **Config paths are wrong**: omp uses `config.json` (not `config.yml`) and `models.yml`, located at `~/.omp/` or `.omp/` in the project root.

6. **Skill paths are unverified**: `~/.omp/agent/skills/` and `.omp/skills/` are not documented in public sources.
