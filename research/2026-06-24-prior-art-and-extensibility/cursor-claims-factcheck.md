### Key Findings

1. **`cursor-hook-bridge.sh` is NOT a Cursor concept** — it's a Silver Bullet project artifact. Cursor uses `hooks.json` natively.
2. **`additionalContext` is NOT a PreToolUse output** — it only exists on `postToolUse`. Claim #5 is unverified/wrong for PreToolUse.
3. **`postCompact` does NOT exist** — only `preCompact` is in Cursor's hook list. This is confirmed.
4. **`PermissionRequest` is NOT supported** in the third-party hooks matrix — claim #20 is verified.
5. **Skills ≠ plugin cache** — Cursor has an open Agent Skills standard, not a "plugin cache" system.
6. **"alo-labs-cursor-marketplace"** is not referenced in any official Cursor documentation.
7. **`updated_input` on beforeSubmitPrompt** is NOT documented — only `permission`, `user_message`, `agent_message` for blocking hooks.
8. **`Skill` as a matcher value** is NOT documented — only `Shell`, `Read`, `Write`, `Grep`, `Delete`, `Task`, `MCP:*`.
